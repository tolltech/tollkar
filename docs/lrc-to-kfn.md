# Конвертация LRC и MP3 в KFN

Скрипт `scripts/lrc-to-kfn.py` конвертирует пары файлов с одинаковым именем:

```sh
python3 scripts/lrc-to-kfn.py /path/to/Karaoke2017 --output-dir /path/to/kfn
```

По умолчанию выходные `.kfn` записываются рядом с исходными файлами. Для замены уже
существующих файлов добавьте `--overwrite`.

Скрипт распознаёт UTF-8 и CP1251, сохраняет MP3 без перекодирования и использует `ffprobe`,
если он доступен, чтобы оценить длительность последней строки. В LRC обычно указано только
время начала строки, поэтому времена слов внутри строки интерполируются до следующей строки.
