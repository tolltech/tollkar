# Конвертация CDG и MP3 в KFN

Скрипт `scripts/cdg-to-kfn.py` рекурсивно находит пары CDG/MP3, преобразует графику CDG
в совместимый с браузером MP4-фон и упаковывает фон вместе с исходным MP3 в KFN.
Текст и подсветка находятся в самом видео: отдельных строк KFN нет (`TextCount=0`).
Плеер сохраняет область изображения и для таких файлов. Если старый плеер показывал
чёрный экран, обновите веб-клиент и перезагрузите страницу; повторная конвертация не нужна.
По умолчанию используются каталоги:

- источник — `/Volumes/tollcloud/klavish`;
- результат — `/Volumes/tollcloud/karaoke/klavish`.

Запуск с каталогами по умолчанию:

```sh
python3 scripts/cdg-to-kfn.py
```

Для предварительного просмотра без записи файлов используйте `--dry-run`. Повторный запуск
пропускает уже созданные KFN; `--overwrite` разрешает их безопасную замену. Пути можно изменить:

```sh
python3 scripts/cdg-to-kfn.py /path/to/cdg --output-dir /path/to/kfn
```

Требуется `ffmpeg` с декодером `cdgraphics` и кодировщиком `libx264`. Дерево подпапок источника
сохраняется. Исполнитель и название берутся из имени папки вида `Исполнитель - Название`, причём
обозначения версии вроде `(SC)` остаются частью названия.

Сначала сопоставляются файлы с одинаковым базовым именем без учёта регистра. Если в папке находится
ровно один CDG и один MP3, они считаются парой даже при небольшой опечатке в
имени. MP3 без CDG не обрабатываются, а CDG без подходящего MP3 выводятся как `SKIP`.
